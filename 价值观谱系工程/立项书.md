## 一、研究问题分解

**总问题**：价值观如何产生、如何传递、如何变迁——从生命起源到算法时代；终章回答：天人合一作为价值观意味着什么、带来了什么、怎样被淡化、今天意味着什么。

**站点分解**（每站=一个研究单元）：

| 站 | 时段 | 核心问题 |
|---|---|---|
| S1 | 生命起源—旧石器 | 评价机制如何从趋避行为演化为群体规范（含平等主义之谜） |
| S2 | 农业革命 | 剩余如何重写价值观（等级正当化的机制） |
| S3 | 轴心时代 | 价值观反思为何在此时多地同发（天人合一母腹） |
| S4 | 帝制整合 | 天人合一的制度化：约束与征用的双面账 |
| S5 | 近代断裂 | 天人合一淡化的真实机制（逐段断电假说检验） |
| S6 | 现代加速 | 世代更替与压缩现代性的实证（Inglehart/曼海姆/米德） |
| S7 | 算法时代 | 价值观生产工业化：设计、推荐、喂养 |
| T | 终章 | 天人合一：意义/代价/淡化/当代重编码可能性 |

## 二、方法论（每站四步，固定流程）

1. **文献核查**：scholar检索关键命题的支持与争议文献，数据存《文献数据/》；无文献支撑的主张降级为【框架读法】或【推测】。
2. **假说登记**：本站核心假说写入《假说登记簿.md》，格式=假说+证据+反例+置信层（史实/框架/推测）。
3. **反例强制**：每站至少登记1个对工程主框架构成压力的反例（R-9：无反例=零信息）。
4. **压力测试**：站点结论过简化版五项攻击（极限边界/对立解释/与工程主框架冲突/自指/伦理挪用）。

## 三、工程主框架（待检验，非前提）

"价值观=环境稀缺结构的编码；编码介质随环境变化速率换挡（基因→文化→制度→教育/工业）；代际落差=低速存量对高速流量的正常响应。"——本框架本身是被检验对象，每站可击伤它；若某站致命，修订框架而非裁剪史实。

## 四、终章产出判据（天人合一答复必须全过）

- J1 史实底座：每主张有文献支撑或明确置信标注；
- J2 反例登记：全工程累计≥3个未解决反例随终章一并交付；
- J3 奥卡姆收费口（2.4.1·P2）：明确回答"本谱系学比直线进步史观/衰退史观多判出什么、少误判什么"，答不出则相关结论降级为比喻；
- J4 三层置信：史实/框架/推测全标注；
- J5 体系接缝审查：天人合一与生命逻辑的关系声明过2.8六项校验+2.7防玄学化审查（防"天人合一=生命逻辑古称"式附会）。
